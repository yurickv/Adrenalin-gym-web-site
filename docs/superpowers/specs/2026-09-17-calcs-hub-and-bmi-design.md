## 1. Контекст і мета

Search Console за період зі скріншотів:

| Сторінка | Кліки | Покази | CTR | Позиція |
|---|---|---|---|---|
| /calcs/imt-calculator | 8 | 2446 | 0,3% | 14,9 |
| /calcs | 1 | 21 | 4,8% | 7,7 |

Сторінка ІМТ стоїть на другій сторінці видачі. Конкуренти в топі (DOZA, Astramedika, Apollo)
показують ідеальну вагу, норму ваги за зростом і вікові норми, мають лікарські байлайни.
Хаб має тонкий контент: H1 «Калькулятори», три вкладки і фото; без canonical, OG,
BreadcrumbList; на нього не веде жодне посилання з шапки чи футера.

Мета:

1. ІМТ закриває інтенти «імт калькулятор», «калькулятор ідеальної ваги», «норма ваги за
   зростом», «імт калькулятор з віком»: показує категорію за ВООЗ, діапазон норми ваги,
   ідеальну вагу за Девіном і вікову норму.
2. Хаб отримує повні метадані, структуровані дані, змістовний текст і посилання з навігації.
3. Через 4–6 тижнів після деплою: ІМТ у топ-10 за «імт калькулятор» (з 14,9), CTR
   сторінки не менше 2% (з 0,3%). Локальні Lighthouse: performance не гірше 90,
   accessibility 100, SEO 100 на обох сторінках.

## 5. ІМТ: чистий модуль `lib/bmi.ts`

Функції без побічних ефектів, покриті vitest (`lib/bmi.test.ts`):

- `BMI_LIMITS = { height: { min: 120, max: 230 }, weight: { min: 30, max: 250 }, age: { min: 18, max: 100 } }`.
- `bmi(weightKg, heightCm): number` — вага / (зріст у м)², один знак.
- `type BmiCategory = 'underweight' | 'normal' | 'overweight' | 'obese1' | 'obese2' | 'obese3'`;
  `bmiCategory(value)`: < 18,5; 18,5–24,9; 25–29,9; 30–34,9; 35–39,9; ≥ 40.
  `BMI_CATEGORY_LABELS: Record<BmiCategory, { label; range; advice }>` з українськими
  текстами: «Недостатня вага», «Норма», «Надлишкова вага», «Ожиріння I ступеня», «Ожиріння
  II ступеня», «Ожиріння III ступеня»; `advice` — одне речення поради, як у поточних
  повідомленнях, без вигуків.
- `normalWeightRange(heightCm): { min: number; max: number }` — 18,5·h² і 24,9·h² у кг,
  округлені до цілого (170 см → 53–72).
- `weightToNormal(weightKg, range): number` — 0 у діапазоні; від'ємне, скільки скинути до
  `max`; додатне, скільки набрати до `min`. Ціле число.
- `devineIdealWeight(sex, heightCm): number | null` — чоловіки 50 + 0,9·(h − 152), жінки
  45,5 + 0,9·(h − 152), округлення до цілого; `null` для зросту < 152.
- `AGE_BMI_NORMS = [ { from: 18, to: 24, min: 19, max: 24 }, { from: 25, to: 34, min: 20, max: 25 },
  { from: 35, to: 44, min: 21, max: 26 }, { from: 45, to: 54, min: 22, max: 27 },
  { from: 55, to: 64, min: 23, max: 28 }, { from: 65, to: 100, min: 24, max: 29 } ]`;
  `ageBmiNorm(age): AgeBmiNorm | null` — рядок таблиці або `null` для віку поза 18–100.
- `HEIGHT_TABLE_ROWS = [150, 155, …, 195]` для таблиці «Норма ваги за зростом».

Контрольні приклади для тестів: 170 см, 65 кг → ІМТ 22,5, `normal`, діапазон 53–72,
до норми 0, Девін ч 66 / ж 62; 170 см, 80 кг → 27,7, `overweight`, до норми −8;
160 см, 45 кг → 17,6, `underweight`, до норми +2 (діапазон 47–64); 150 см → Девін
`null`; вік 30 → норма 20–25; вік 17 → `null`.
