- Сторінка: `/calcs/fat-calculator` (`app/calcs/fat-calculator/page.tsx`)
- Статус: дизайн затверджено користувачем 17.09.2026 (варіанти А, А)

- Попередні етапи: PR 1–3 (калорії), PR 4 (хаб і ІМТ)

## 1. Контекст і мета

Search Console: сторінка жиру має 85 кліків, 3224 покази, CTR 2,6%, позиція 7,4; запит
«відсоток жиру в організмі калькулятор» на позиції 8,7. Зараз калькулятор рахує лише за
трьома шкірними складками, для чого потрібен каліпер або лінійка і напарник. Конкуренти з
топу (Apollo, Budokan, Flapane) рахують за обхватами сантиметровою стрічкою, метод ВМС США.

Мета:

1. Сторінка рахує відсоток жиру двома методами; за замовчуванням метод за обхватами, який
   доступний кожному без інструментів.
2. Результат показує також кілограми жиру і сухої маси, якщо введено вагу.
3. Через 4–6 тижнів після деплою: позиція за «відсоток жиру в організмі калькулятор» у топ-5
   (з 8,7), CTR сторінки не менше 4% (з 2,6%). Локальний Lighthouse: performance не гірше 90,
   accessibility 100, SEO 100.

## 4. Чистий модуль `lib/bodyFat.ts` з тестами

- `FAT_LIMITS = { height: 120–230, neck: 20–60, waist: 40–200, hip: 50–200, age: 14–100,
  skinfold: 1–100, weight: 30–250 }`.
- `type FatMethod = 'tape' | 'caliper'`.
- `navyBodyFat(sex, { heightCm, neckCm, waistCm, hipCm? }): number | null`, у сантиметрах:
  чоловіки `495 / (1.0324 − 0.19077·log10(талія − шия) + 0.15456·log10(зріст)) − 450`,
  жінки `495 / (1.29579 − 0.35004·log10(талія + стегна − шия) + 0.22100·log10(зріст)) − 450`.
  `null`, якщо для чоловіка талія ≤ шия, для жінки талія + стегна ≤ шия або стегна не задані.
  Округлення до одного знака.
  Контрольні приклади: чоловік 180 см, шия 38, талія 90 → 19,8%; жінка 165 см, шия 33,
  талія 75, стегна 98 → 28,4%; чоловік 175, шия 40, талія 80 → 11,1%.
- `jacksonPollockBodyFat(sex, age, sumMm): number` переносить поточні формули з
  `FatCalcFormula.tsx` без змін; контрольні приклади: сума 60 мм, 30 років → чоловік 17,9%,
  жінка 24,1% (поточний FAQ каже «приблизно 18%», лишається).
- `FAT_CATEGORIES: Record<Sex, Array<{ max: number; label: string; note: string }>>`, дані
  з поточних таблиць `FatDescription` і повідомлень `FatCalcFormula`: чоловіки 6, 13, 17, 21,
  25, ∞; жінки 10, 14, 16, 20, 24, 30, ∞. `bodyFatCategory(sex, pct)` повертає рядок довідника.
- `fatMassKg(weightKg, pct)` і `leanMassKg(weightKg, pct)`, один знак: 80 кг і 19,8% →
  15,8 і 64,2.
- `formatPercent(pct)`: один знак, кома.
- `HEALTHY_RANGE = { male: [12, 20], female: [16, 24] }` для тексту сторінки.

## 5. Форма і результат

### 5.1 Форма (`components/calcs-page/FatCalcList.tsx`, переписати)

- Перемикач «Метод» (radiogroup): «За обхватами» за замовчуванням, «За складками».
- Стать (radiogroup, спільні `SEX_OPTIONS`/`toggleClass`).
- Для обхватів: зріст, шия, талія, для жінок стегна; підказка під полями «Стрічка щільно,
  але не втискається в шкіру».
- Для складок: вік і три складки з поточними підписами (для чоловіків груди, живіт, стегно;
  для жінок трицепс, живіт збоку, стегно).
- Вага, необов'язкова, без повзунка (`noRange`).
- Валідація `rangeError`, без yup. Стан полів зберігається при перемиканні методу.

### 5.2 Результат (`components/calcs-page/FatResult.tsx`, замінює `FatCalcFormula.tsx`)

Рендериться, коли всі обов'язкові поля обраного методу заповнені й у лімітах:

- «Відсоток жиру: **19,8%**», категорія з описом («Середній рівень жиру. Звичайна статура,
  середній рівень фізичної активності.»), здоровий діапазон для статі;
- з вагою: «Жирова маса 15,8 кг, суха маса 64,2 кг»;
- для обхватів, якщо талія ≤ шия: підказка «Перевірте виміри: талія має бути більшою за шию»
  замість результату;
- посилання «розрахуйте денну норму калорій і дефіцит для схуднення» на калькулятор калорій;
- завжди присутній `sr-only` рядок з `aria-live="polite"`.

## 9. Ризики

- Метод ВМС дає похибку ±3–4% і чутливий до положення стрічки; текст сторінки чесно каже про
  це і радить міряти в один час доби.
- Зміна форми за замовчуванням може здивувати постійних користувачів каліпера; друга вкладка
  зберігає їхній сценарій без втрат.
